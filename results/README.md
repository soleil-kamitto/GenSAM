# Results

Output files generated by the analysis scripts and notebooks. Organized by biological target.

```
results/
├── bacteria/
│   ├── actinomycetes/   — Actinomyces israelii segmentation results
│   └── ecoli/           — E. coli segmentation results
├── cells/               — General cell culture segmentation results
└── dataset/             — Dataset exploration visualizations
```

Each subfolder contains:
- `.png` — segmentation visualizations and comparison plots
- `.csv` — per-cell metrics (area, eccentricity, solidity, etc.)

These files are generated automatically when you run the scripts. They are included in the repository as reference outputs.

# Results (Español)

Archivos de salida generados por los scripts de análisis y los notebooks. Organizados por tipo de objetivo biológico.

```
results/
├── bacteria/
│   ├── actinomycetes/   — Resultados de segmentación de Actinomyces israelii
│   └── ecoli/           — Resultados de segmentación de E. coli
├── cells/               — Resultados de segmentación de cultivo celular general
└── dataset/             — Visualizaciones de exploración del dataset
```

Cada subcarpeta contiene:
- `.png` — visualizaciones de segmentación y gráficas comparativas
- `.csv` — métricas por célula (área, excentricidad, solidez, etc.)

Estos archivos se generan automáticamente al ejecutar los scripts. Se incluyen en el repositorio como salidas de referencia.
