# Examples

Official CellSAM example scripts (from the original repository) demonstrating segmentation across different imaging modalities and cell types.

| Script | Target |
|--------|--------|
| `plot_electron_microscopy.py` | Electron microscopy |
| `plot_ep_micro.py` | Epithelial cells (phase contrast) |
| `plot_HandE.py` | H&E tissue staining |
| `plot_multiplexed.py` | Multiplexed imaging |
| `plot_yeastnet.py` | Yeast (YeastNet dataset) |
| `plot_yeaz.py` | Yeast (YeaZ dataset) |

These examples use the images in `sample_imgs/` and serve as a starting point for adapting CellSAM to your own data.

# Examples (Español)

Scripts de ejemplo oficiales de CellSAM (del repositorio original) que demuestran la segmentación en distintas modalidades de imagen y tipos celulares.

| Script | Objetivo |
|--------|----------|
| `plot_electron_microscopy.py` | Microscopía electrónica |
| `plot_ep_micro.py` | Células epiteliales (contraste de fase) |
| `plot_HandE.py` | Tinción H&E de tejido |
| `plot_multiplexed.py` | Imagen multiplexada |
| `plot_yeastnet.py` | Levadura (dataset YeastNet) |
| `plot_yeaz.py` | Levadura (dataset YeaZ) |

Estos ejemplos usan las imágenes de `sample_imgs/` y sirven como punto de partida para adaptar CellSAM a tus propios datos.
