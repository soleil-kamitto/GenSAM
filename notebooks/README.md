# Notebooks

Jupyter notebooks for interactive analysis with CellSAM. They can be run locally or on Google Colab.

| Notebook | Description |
|----------|-------------|
| `ecoli_analysis_colab.ipynb` | End-to-end E. coli segmentation and analysis. Designed to run on Google Colab (no local GPU needed). |
| `ecoli_analysis_10images.ipynb` | Batch analysis of 10 E. coli test images with per-image metrics and summary statistics. |

**Open in Google Colab:** Click the "Open in Colab" badge at the top of each notebook.

**Run locally:**
```bash
jupyter notebook notebooks/
```

# Notebooks (Español)

Jupyter notebooks para análisis interactivo con CellSAM. Se pueden ejecutar localmente o en Google Colab.

| Notebook | Descripción |

| `ecoli_analysis_colab.ipynb` | Segmentación y análisis completo de E. coli de extremo a extremo. Diseñado para ejecutarse en Google Colab (no requiere GPU local). |
